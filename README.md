# Adopt Me!

A pet adoption app built with React, from the Frontend Masters "Complete Intro to React" course.

## About The Project

A pet adoption application built while following the course, covering the core React concepts: components, hooks, and client-side tooling.

### Built With

- React 17
- Parcel
- ESLint / Prettier

## Getting Started

Install the dependencies:

```bash
npm install
```

Start the development server (Parcel):

```bash
npm run development
```
